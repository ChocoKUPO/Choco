# 미식노트 — 안드로이드 앱 만들기

이 폴더에는 두 가지가 들어 있습니다.

- `web/` — 앱 본체. 웹서버에 올리면 그대로 앱이 됩니다.
- `android/twa-manifest.json` — 플레이스토어용 APK/AAB를 만들 때 쓰는 설정 파일.

---

## 먼저 알아둘 것

안드로이드 앱을 만드는 길은 두 가지입니다. **1번부터 하시면 됩니다.**

| | 홈 화면 설치 (PWA) | 플레이스토어 앱 (TWA) |
|---|---|---|
| 준비물 | 웹서버만 | 웹서버 + Node.js + 자바 |
| 걸리는 시간 | 10분 | 1시간쯤 |
| 아이콘·전체화면 | 됨 | 됨 |
| 오프라인 | 됨 | 됨 |
| SNS 로그인 | 정상 | 정상 |
| 스토어 배포 | 안 됨 | 됨 |
| 설치 파일(APK) | 없음 | 있음 |

두 방식 모두 **크롬 엔진 위에서 돌아갑니다.** 그래서 구글·카카오 로그인이 정상 작동합니다.
(참고: 앱 안에 웹뷰를 직접 넣는 방식은 구글이 로그인을 막기 때문에 권하지 않습니다.)

---

## 1단계 — 웹서버에 올리기 (필수)

지도, 로그인, 동기화가 모두 **주소가 있어야** 동작합니다. 무료로는 GitHub Pages가 가장 쉽습니다.

1. github.com에서 저장소를 하나 만듭니다. 이름 예: `misiknote`
2. `web/` 안의 파일을 **전부** 저장소에 올립니다. (`.well-known` 폴더도 빠뜨리지 마세요)
3. 저장소 Settings > Pages > Source를 `main` 브랜치로 지정합니다.
4. 몇 분 뒤 주소가 생깁니다: `https://내계정.github.io/misiknote/`

이 주소를 아래 세 곳에 등록해야 합니다.

- **카카오디벨로퍼스** → 앱 > 플랫폼 키 > JavaScript SDK 도메인
  → `https://내계정.github.io` 를 등록
- **Supabase** → Authentication > URL Configuration > Redirect URLs
  → `https://내계정.github.io/misiknote/` 를 등록
- **앱 안 ⚙ 설정** → 카카오 JavaScript 키, Supabase URL·anon key 입력

---

## 2단계 — 휴대폰 홈 화면에 앱으로 설치하기

가장 빠른 길이고, 대부분 이걸로 충분합니다.

1. 안드로이드 크롬에서 위 주소를 엽니다.
2. 우측 상단 ⋮ 메뉴 → **앱 설치** (또는 홈 화면에 추가)
3. 홈 화면에 미식노트 아이콘이 생깁니다.

이렇게 설치하면 주소창 없는 전체화면으로 뜨고, 앱 전환 화면에도 독립된 앱으로 나옵니다.
비행기 모드에서도 앱이 열리고, 저장한 기록은 그대로 보입니다.

아이폰은 사파리에서 **공유 → 홈 화면에 추가**로 같은 결과가 됩니다.

## 3단계 — 설치 파일(APK/AAB) 만들기

플레이스토어에 올리거나, 파일로 직접 설치하고 싶을 때만 하시면 됩니다.

### 준비
- Node.js 18 이상
- JDK 17
- Android SDK (Bubblewrap이 알아서 받아 줍니다)

### 만들기

```bash
# 1. 도구 설치
npm install -g @bubblewrap/cli

# 2. 내 사이트 주소로 프로젝트 만들기
bubblewrap init --manifest=https://내계정.github.io/misiknote/manifest.webmanifest

#    묻는 것들: 패키지 이름은 kr.misiknote.app 정도로,
#    서명키는 새로 만들기(create new)를 고르고 비밀번호를 정합니다.
#    비밀번호는 반드시 따로 적어 두세요. 잃어버리면 앱 업데이트를 못 합니다.

# 3. 빌드
bubblewrap build

#    결과물
#    app-release-signed.apk   ← 휴대폰에 직접 설치용
#    app-release-bundle.aab   ← 플레이스토어 업로드용
```

`android/twa-manifest.json`은 위 `init` 대신 쓸 수 있는 설정 견본입니다.
`내계정.github.io` 부분을 본인 주소로 바꾼 뒤 프로젝트 폴더에 넣고 `bubblewrap build`만 해도 됩니다.

### 주소창 없애기 (중요)

빌드하면 서명키의 지문이 출력됩니다. 이걸 사이트에 등록해야 주소창이 사라집니다.

```bash
bubblewrap fingerprint list
```

여기서 나온 SHA-256 값을 `web/.well-known/assetlinks.json`의
`여기에_내_서명키_SHA256_지문을_넣으세요` 자리에 붙여넣고 다시 올리세요.

등록이 안 되어 있으면 앱을 열 때 위에 주소창이 남습니다. 동작은 하지만 앱 같아 보이지 않습니다.

## 자주 막히는 곳

**지도가 회색으로만 나옵니다**
카카오 JavaScript SDK 도메인에 주소를 등록했는지 확인하세요. 프로토콜까지 정확히 적어야 합니다
(`https://내계정.github.io`, 끝에 슬래시 없이).

**로그인 버튼을 누르면 오류가 납니다**
Supabase의 Redirect URLs에 앱 주소가 정확히 들어가 있는지 확인하세요. 마지막 슬래시까지 같아야 합니다.

**앱을 지웠더니 기록이 사라졌습니다**
로그인하지 않은 상태였을 겁니다. 로그인해 두면 계정에 남습니다. 로그인을 안 쓰실 거라면
공유 탭의 **파일로 내보내기**로 가끔 백업해 두세요.

**앱을 다시 설치했더니 로그인이 풀렸습니다**
정상입니다. 같은 계정으로 다시 로그인하면 기록이 그대로 돌아옵니다.
