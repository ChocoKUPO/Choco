# 미식노트 — 안드로이드 앱 만들기

이 폴더에는 두 가지가 들어 있습니다.

- `web/` — 앱 본체. 웹서버에 올리면 그대로 앱이 됩니다.
- `android/twa-manifest.json` — 플레이스토어용 APK/AAB를 만들 때 쓰는 설정 파일.

---

## 먼저 알아둘 것

안드로이드 앱을 만드는 길은 두 가지입니다. **1번부터 하시면 됩니다.**

| | 홈 화면 설치 (PWA) | 플레이스토어 앱 (TWA) |
|---|---|---|
| 준비물 | 웹서버만 | 웹서버 + Node.js + 자바 |
| 걸리는 시간 | 10분 | 1시간쯤 |
| 아이콘·전체화면 | 됨 | 됨 |
| 오프라인 | 됨 | 됨 |
| 로그인 | 없음 | 없음 |
| 스토어 배포 | 안 됨 | 됨 |
| 설치 파일(APK) | 없음 | 있음 |

두 방식 모두 **크롬 엔진 위에서 돌아갑니다.**

---

## 1단계 — 웹서버에 올리기 (필수)

지도와 동기화가 모두 **주소가 있어야** 동작합니다. 무료로는 GitHub Pages가 가장 쉽습니다.

1. github.com에서 저장소를 하나 만듭니다. **이름은 정확히 `Choco`** (대문자 C — 주소의 대소문자가 저장소 이름과 같아야 합니다).
2. `web/` 안의 파일을 **전부** 저장소에 올립니다. (`.well-known` 폴더도 빠뜨리지 마세요)
3. 저장소 Settings > Pages > Source를 `main` 브랜치로 지정합니다.
4. 몇 분 뒤 주소가 생깁니다: `https://chocokupo.github.io/Choco/`

이 주소를 아래 세 곳에 등록해야 합니다.

- **카카오디벨로퍼스** → 앱 > 플랫폼 키 > JavaScript SDK 도메인
  → `https://chocokupo.github.io` 를 등록
- **소스 코드 `BUILTIN_KAKAO_KEY`** → 카카오 JavaScript 키를 여기에 한 번 넣으면 모든 사용자가 지도를 씁니다
  (index.html 위쪽. 카카오디벨로퍼스 > 앱 키 > JavaScript 키. 플랫폼 Web 도메인에 `https://chocokupo.github.io` 등록)

---

## 2단계 — 휴대폰 홈 화면에 앱으로 설치하기

가장 빠른 길이고, 대부분 이걸로 충분합니다.

1. 안드로이드 크롬에서 위 주소를 엽니다.
2. 우측 상단 ⋮ 메뉴 → **앱 설치** (또는 홈 화면에 추가)
3. 홈 화면에 미식노트 아이콘이 생깁니다.

이렇게 설치하면 주소창 없는 전체화면으로 뜨고, 앱 전환 화면에도 독립된 앱으로 나옵니다.
비행기 모드에서도 앱이 열리고, 저장한 기록은 그대로 보입니다.

아이폰은 사파리에서 **공유 → 홈 화면에 추가**로 같은 결과가 됩니다.

---

## 3단계 — 설치 파일(APK/AAB) 만들기

플레이스토어에 올리거나, 파일로 직접 설치하고 싶을 때만 하시면 됩니다.

### 준비
- Node.js 18 이상
- JDK 17
- Android SDK (Bubblewrap이 알아서 받아 줍니다)

### 만들기

```bash
# 1. 도구 설치
npm install -g @bubblewrap/cli

# 2. 내 사이트 주소로 프로젝트 만들기
bubblewrap init --manifest=https://chocokupo.github.io/Choco/manifest.webmanifest

#    묻는 것들: 패키지 이름은 kr.chocokupo.choco 정도로,
#    서명키는 새로 만들기(create new)를 고르고 비밀번호를 정합니다.
#    비밀번호는 반드시 따로 적어 두세요. 잃어버리면 앱 업데이트를 못 합니다.

# 3. 빌드
bubblewrap build

#    결과물
#    app-release-signed.apk   ← 휴대폰에 직접 설치용
#    app-release-bundle.aab   ← 플레이스토어 업로드용
```

`android/twa-manifest.json`은 위 `init` 대신 쓸 수 있는 설정 견본입니다.
이미 `chocokupo.github.io`로 채워져 있으니, 프로젝트 폴더에 넣고 `bubblewrap build`만 해도 됩니다.

### 주소창 없애기 (중요)

빌드하면 서명키의 지문이 출력됩니다. 이걸 사이트에 등록해야 주소창이 사라집니다.

```bash
bubblewrap fingerprint list
```

여기서 나온 SHA-256 값을 `web/.well-known/assetlinks.json`의
`여기에_내_서명키_SHA256_지문을_넣으세요` 자리에 붙여넣고 다시 올리세요.

등록이 안 되어 있으면 앱을 열 때 위에 주소창이 남습니다. 동작은 하지만 앱 같아 보이지 않습니다.

## 자주 막히는 곳

**지도가 회색으로만 나옵니다**
카카오 JavaScript SDK 도메인에 주소를 등록했는지 확인하세요. 프로토콜까지 정확히 적어야 합니다
(`https://chocokupo.github.io`, 끝에 슬래시 없이).

**기록이 사라졌습니다**
브라우저 데이터를 지웠거나 앱을 재설치했을 겁니다. 로컬 저장이라 그러면 사라집니다. 백업 파일을 불러오면 되살아납니다. 평소 가끔 **파일로 내보내기**를 해두세요.

**앱을 지웠더니 기록이 사라졌습니다**
로컬에만 저장되기 때문입니다. 공유 탭의 **파일로 내보내기**로 가끔 백업해 두세요.

**기기를 바꿨더니 기록이 안 보입니다**
로컬 저장이라 기기 간에 자동으로 옮겨지지 않습니다. 이전 기기에서 **파일로 내보내기** 한 백업을 새 기기에서 **파일 불러오기** 하면 됩니다.

## 저장한 맛집 보기 · 수정 · 리뷰

- 목록에서 카드를 누르면 **보기 화면(뷰어)** 가 열립니다. 바로 수정되지 않습니다.
- 보기 화면 우측 상단 **수정** 버튼을 눌러야 편집으로 들어갑니다.
- 보기 화면 아래쪽에 **네이버 블로그 후기**가 붙습니다.

### 리뷰 (네이버 블로그·지도)

보기 화면 아래 **리뷰** 항목은 네이버로 연결되는 링크입니다. 별도 준비물이 없습니다.

- **네이버 블로그 후기** — 가게 이름·주소로 블로그 검색이 새 탭에서 열립니다.
- **네이버 지도 · 방문자 리뷰** — 그 가게의 네이버 지도 페이지(평점·방문자·블로그 리뷰)로 이동합니다.
- **카카오맵 상세** — 상호 검색으로 저장한 가게라면 카카오맵 페이지도 함께 뜹니다.

가게 이름이 흔하거나 지점이 여럿이면 다른 지점 결과가 섞일 수 있습니다.
상호 검색(관리자에서 카카오 키를 넣으면 켜짐)으로 저장한 가게일수록 정확합니다.

## 저장 방식 (이 기기에만)

로그인이 없습니다. 저장한 맛집은 **그 기기(브라우저)에만** 보관됩니다.
서버로 올라가지 않으니 준비할 것도, 설정할 것도 없습니다.

- 저장·수정하면 바로 그 기기에 남습니다. 다시 열어도 그대로 있습니다.
- **주의:** 앱(홈 화면 아이콘)을 지우거나, 브라우저 데이터를 지우거나, 기기를 바꾸면
  기록이 사라집니다. 클라우드 백업이 없기 때문입니다.
- 그래서 **백업이 유일한 보존 수단**입니다. 설정 > 백업, 또는 공유 탭의
  **파일로 내보내기**로 가끔 파일을 저장해 두세요. 새 기기에서는 **파일 불러오기**로 되살립니다.

여러 사람이 같은 홈페이지를 열어도, 각자 기기에 각자 기록이 따로 쌓입니다.
서로의 기록은 섞이지 않습니다. 남과 목록을 나누고 싶을 때만 공유 탭의 코드/파일로 주고받으면 됩니다.
