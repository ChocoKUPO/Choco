🔧 관리자

이 화면은 앱을 처음 세팅하는 사람만 씁니다. 여기 넣는 값은 이 기기에만 저장되고, 일반 사용자에게는 보이지 않습니다. 세팅이 끝나면 다시 열 일이 없습니다.

1. 카카오맵 JavaScript 키

모든 사용자에게 적용하려면 소스 코드(index.html) 위쪽의 BUILTIN_KAKAO_KEY 한 줄에 키를 넣으세요. 한 번 넣으면 이 앱을 여는 누구나 같은 키로 지도를 씁니다.

아래 칸은 이 기기에서만 임시로 키를 시험할 때 쓰는 자리입니다. 여기 넣은 값은 소스에 심은 키보다 우선하지만, 이 기기에만 저장됩니다.

2. 로그인 서버 (Supabase)

모든 사용자에게 적용하려면 소스 코드(index.html) 위쪽의 BUILTIN_SB_URL과 BUILTIN_SB_KEY 두 줄에 값을 넣으세요. 한 번 넣으면 이 앱을 여는 누구나 카카오 로그인을 씁니다.

아래 칸은 이 기기에서만 임시로 시험할 때 쓰는 자리입니다. 여기 넣은 값은 소스에 심은 값보다 우선하지만, 이 기기에만 저장됩니다.

3. 로그인 서버 준비 순서

  1. supabase.com 가입 후 프로젝트 생성 (무료)
  2. Authentication > Providers에서 Kakao 켜기 (카카오디벨로퍼스 REST API 키·시크릿 입력, 카카오 쪽에 콜백 URL 등록)
  3. Authentication > URL Configuration의 Redirect URLs에 https://chocokupo.github.io/Choco/ 추가
  4. SQL Editor에서 아래 문장 실행 (각자 자기 데이터만 보이게 하는 표·규칙)
  5. Settings > API의 URL과 anon key를 위 2번에 붙여넣기
